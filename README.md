<h1 align="center">日迹 · DailyToDo</h1>

<p align="center">记录日常工作，管理待办，按需整理工作报告。</p>

日迹是一款本地优先的桌面备忘录应用。日常记录无需联网，数据保存在本机，支持离线整理和可选的 AI 报告生成。

## 功能

- 📝 **每日记录**：按日期记录备忘、工作进展与问题，支持标签、编辑和搜索。
- ✅ **待办清单**：随手记下待办，可选填项目（不固定，自由输入）、优先级和耗时；未完成事项可顺延并记录风险或原因，可标记插活，并记录完成时间。
- 📋 **每周计划**：关联日常待办，按周记录进展和阻塞原因，未完成计划自动延续，周报对照上周与本周。
- 🖼️ **图片附件**：上传或粘贴图片，支持多图预览和纯图片记录。
- 📄 **工作报告**：统一生成日报、周报、月报，自选日期范围，使用待办事项，周报还支持周计划对照；支持自定义模板、本地整理或 AI 生成。
- 📊 **统计回顾**：按周、月、年查看完成率、耗时、预估准确度、完成趋势、项目分布、积压待办和记录热力图，并可导出待办 CSV。
- 💾 **备份导出**：复制或导出 Markdown 报告，通过 JSON 备份与合并导入本地数据。

## 启动

开发环境：Node.js 22.12+、Rust 1.90+；Windows 还需 C++ 构建工具和 WebView2。

```powershell
npm ci
npm run desktop
```

仅预览界面可运行 `npm run dev`，访问 `http://127.0.0.1:1493`。浏览器预览数据与桌面数据独立，AI 功能在桌面端使用。

使用 `npm run desktop:build` 构建 Windows 程序与安装包，产物位于 `src-tauri/target/release/`。

## AI 与数据

AI 为可选功能，支持 OpenAI 兼容接口和本地 Ollama。生成时发送所选日期内的待办事项、待办统计、报告模板及补充要求；周报另外发送完整周的计划、前一周对照及关联待办参考；远程服务可能产生调用费用。API Key 保存在系统凭据库，不进入备份。可选配置 GitHub／GitLab 访问令牌，生成 AI 报告时勾选后附带你的提交标题作为进度参考，令牌同样只保存在系统凭据库。
